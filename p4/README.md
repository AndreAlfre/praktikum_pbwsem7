# Praktikum Web - PHP MVC (Akademik & Penjualan)

Proyek ini berisi dua aplikasi web sederhana berbasis PHP Native yang dibangun menggunakan pola arsitektur **MVC (Model-View-Controller)**. 

---

## 1. Proyek: Akademik MVC (`akademik-mvc`)
Aplikasi web sederhana untuk menampilkan data mahasiswa dari database. Proyek ini mendemonstrasikan bagaimana konsep MVC memisahkan antara logika pengambilan data (Model), tata letak tampilan (View), dan penghubung alur aplikasi (Controller).

* **Database yang digunakan:** `akademik`
* **Tabel:** `mahasiswa` (NPM, Nama, Email, Prodi, Angkatan, IPK)

## 2. Proyek: Penjualan MVC (`penjualan-mvc`)
Aplikasi web dengan fungsionalitas **CRUD (Create, Read, Update, Delete)** penuh untuk mengelola data inventaris produk. Aplikasi ini memiliki interaksi database yang lebih dinamis dibanding proyek akademik.
